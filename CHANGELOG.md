### TLDR:

This is a major update to the mod.
It extends the functionality of the mod from just applying armor trims to armor from mobs, to applying armor trims to almost all natural armor sources.
Due to the new functionality, the old name `Mob Armor Trims` is outdated and misleading. Thus, the mod has been renamed to `Naturally Trimmed` instead.

This update also implements some long requested features, like support for the [Trimmable Tools](https://modrinth.com/datapack/trimmable-tools) and [Tool Trims](https://modrinth.com/mod/tool-trims-mod) mod and a pattern blacklist feature.
Additionally, with this update, large parts of the mod have been rewritten and revamped. This includes all of the configuration system, which now has been moved to the json5 file format using quilt parser, and a lot more.

### Full Changelog:

- Added trim loot tables feature
  - All armor pieces generated by loot tables will now have a chance of having an armor trim applied
  - This includes chests from all structures (for example, bastions or end cities), piglin bartering and fishing
- Added trim trades feature
  - All armor pieces in villager trades will now have a chance of having an armor trim applied
- Added trim material blacklist
  - This supports regex patterns
  - By default, all trim tools patterns are blacklisted since they only work for tools
  - A button for validating this blacklist has been added to the `Utils` tab inside the config screen
- Added support for [Trimmable Tools](https://modrinth.com/datapack/trimmable-tools) and [Tool Trims Mod](https://modrinth.com/mod/tool-trims-mod)
  - When either of these mods is present, not only armor will be trimmed, but tools as well. This works for all three trimming features
  - The [Tool Trims Datapack](https://modrinth.com/datapack/tool-trims) is **not** supported
- Added support for multiple armor materials inside custom trim combinations instead of just one armor material


- Rewrote the configuration system
  - Revamped config layout
  - Now uses the json5 file format using quilt parser instead of the toml file format using night config
  - Switching to json5 allows representing custom trim combinations and the general config much better and fixes being stuck on older night config versions
  - Old config files are not supported and would have to be manually migrated
- Revamped config screen
- Added settings for most of the added features in this update
- Added settings to enable/disable specific trimming features
- Improved existing `Validate Trim Combinations` button


- Fixed armor from piglins not being trimmed
- Added Fabric API as a dependency
- Removed explicit stacked armor trims support


- Move to new name: `Naturally Trimmed`
  - Due to the new extended functionality of the mod, the old name `Mob Armor Trims` is no longer fitting
- Move from MIT to GNU LGPLv3 license.
